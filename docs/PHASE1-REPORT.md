# گزارش فاز ۱ — تکمیل معماری و توسعه پلتفرم چندخدمتی نیروکار

تاریخ ثبت: پایان مرحله ۱ (پیش‌انتشار `0.1.0` — بیلد `001`)
این گزارش بر اساس **واقعیت اجرا و تست** نوشته شده، نه بر اساس آنچه «قرار بود» ساخته شود.

---

## ۱) چه چیزهایی واقعاً ساخته شده‌اند؟

### وب‌سایت (Next.js 16 + React + TypeScript) — فعال و در حال اجرا
- صفحه اصلی واکنش‌گرا (موبایل/تبلت/دسکتاپ) با سه ورودی کاملاً متمایز: مشتری (سبزآبی)، نصاب (سرمه‌ای)، فروشگاه (مرجانی)
- فرم‌های ورود سه نقش با اعتبارسنجی واقعی سمت کاربر (موبایل `09xxxxxxxxx`، ایمیل، رمز ≥۶، نرمال‌سازی ارقام فارسی/عربی)
- ناوبری واقعی hash با پشتیبانی از دکمه بازگشت مرورگر؛ ناوبری بالایی در دسکتاپ، نوار پایین شناور در موبایل
- صفحات راهنما و درباره ما
- **صفحه وضعیت توسعه** (`#/status`) با ماتریس امکانات زنده از `packages/shared`
- **پنل مدیریت** (`#/admin`): ورود نمایشی با ۵ نقش، داشبورد، ۹ منو، ماتریس RBAC واقعی، نمونه تاریخچه Append-Only سفارش
- لایه Repository با قرارداد `AuthRepository` و خطای صادقانه `PhaseNotImplementedError` (حفظ‌شده از قبل)

### اپ موبایل (Expo + React Native + TypeScript) — کد کامل
- `apps/mobile`: صفحه آغازین با سه نقش، فرم‌های ورود با اعتبارسنجی مشترک، راهنما، درباره ما
- expo-router، RTL با I18nManager، داده نقش‌ها/اعتبارسنجی/نسخه از `packages/shared`
- `eas.json` + دستور ساخت APK مستند شده

### پکیج مشترک و Monorepo
- `packages/shared`: roles-core، validation، admin-rbac (۵ نقش/۱۷ مجوز)، feature-matrix، version-core
- `packages/config`: tsconfig پایه + env.example (بدون هیچ مقدار واقعی)
- `apps/api`: ساختار و مرز ۹ ماژول آینده — **غیرعملیاتی** طبق دستور

### CI/CD و مستندات
- `.github/workflows/ci.yml`: کیفیت وب (lint + tsc + build) + تایپ موبایل + ساخت APK و Artifact
- `.github/workflows/flutter-apk.yml` (میراث): بدون تغییر حفظ شد
- `docs/`: ARCHITECTURE، FEATURE_PARITY_MATRIX، ROADMAP، VERSIONING
- به‌روزرسانی `README.md` و `SECURITY.md` (بخش امنیت پنل مدیریت)

## ۴) تست‌های ناموفق / محدودیت‌ها

- کلیک‌های اتوماسیون روی دکمه ورود پنل در چند تلاش اول قبل از hydrate کامل اثر نکردند
  (محدودیت ابزار تست، نه اپ — ورود با کلیک واقعی DOM و تعامل انسانی درست کار می‌کند).
- اپ موبایل در این محیط ابری اجرا و Build نشده (Expo/اندروید SDK ندارد)؛ تایپ آن در CI
  بررسی می‌شود و ساخت APK به GitHub Actions موکول است.
- تست‌های خودکار جدید (unit/integration) طبق محدودیت محیط توسعه نوشته نشد؛ تست‌های
  Flutter میراث حفظ شده‌اند.
