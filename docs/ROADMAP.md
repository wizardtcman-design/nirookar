# نقشه راه توسعه — الزامات آینده ثبت‌شده از فاز ۱

> این موارد طبق دستور مالک از همین ابتدا در معماری لحاظ شده‌اند؛ پیاده‌سازی
> هر یک نیازمند تأیید جداگانه است.

## ۱) پیگیری زنده سفارش (فاز ۲)

مشتری مراحل سفارش را مرحله‌به‌مرحله می‌بیند. هر تغییر وضعیت شامل:

- وضعیت قبلی → وضعیت جدید
- شخص انجام‌دهنده تغییر + نقش او
- تاریخ و ساعت دقیق
- توضیحات
- امکان پیوست عکس/ویدئو در صورت نیاز

**طراحی فنی:** تاریخچه Append-Only سمت سرور (قابل دستکاری نیست)؛ نمونه UI این
طراحی در پنل مدیریت فاز ۱ (بخش سفارش‌ها → تاریخچه) پیاده شده است.

## ۲) رسیدگی به خسارت مشتری (فاز ۳)

اگر فروشگاه یا نصاب به مشتری خسارت وارد کند، سازوکار مشخص رسیدگی و جبران وجود دارد
و **اولویت با رسیدگی منفقانه و جبران خسارت مشتری است**.

مواردی که باید طراحی و بررسی شوند (هیچ‌کدام بدون تأیید مالک قطعی نمی‌شود):

- ثبت و مستندسازی شکایت + مدارک و شواهد
- بررسی مسئولیت طرفین بر اساس قراردادها و تعهدات
- سازوکار جبران خسارت و ضمانت اجرای متناسب (جریمه/محدودیت)
- امکان استفاده از بیمه یا ضمانت معتبر
- بررسی الزامات قانونی و حقوقی

⚠️ **نکته ثبت‌شده:** چک یا سفته به‌تنهایی تضمین امنیت یا جبران خسارت نیست.

## ۳) درآمدزایی (فاز ۳ — جایگاه معماری آماده است)

مدل‌های درآمدی که ساختار آینده باید مدیریت کند:

- کمیسیون سفارش
- اشتراک ماهانه
- خدمات ویژه
- فروش محصولات
- سایر مدل‌های قابل بررسی

در فاز ۱ فقط جایگاه معماری (ماژول finance در `apps/api` + بخش مالی پنل) مشخص شده است.

## ۴) گسترش جغرافیایی و نقش‌ها

- فعلاً فقط **تهران** فعال است؛ افزودن شهر از طریق تنظیمات پنل مدیریت (فاز آینده).
- نقش‌های آینده ثبت‌شده: راننده وانت‌بار، شرکت حمل‌ونقل، متخصص تعمیرات —
  افزودن هر نقش فقط یک entry در `packages/shared/src/roles-core.ts` است.

## ۵) مهاجرت‌های فنی ثبت‌شده (نیازمند تأیید)

| مهاجرت | دلیل | وضعیت |
|---|---|---|
| وب → `apps/web` (Monorepo کامل) | ساختار استاندارد مخزن | منتظر تأیید |
| حذف `flutter_app/` | تعویض فناوری موبایل به Expo | منتظر تأیید |
| Backend عملیاتی (NestJS؟ + PostgreSQL؟) | نیاز واقعی داده و کاربران | منتظر تأیید |
| پنل مدیریت → دامنه/سرویس مستقل | امنیت و استقرار | منتظر تأیید |
| ناوبری hash → مسیرهای واقعی Next.js | SEO کامل و اشتراک‌گذاری لینک | منتظر تأیید |
