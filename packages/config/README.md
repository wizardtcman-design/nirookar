# packages/config — تنظیمات و پیکربندی مشترک

جایگاه تنظیمات مشترک Monorepo (فاز ۱: حداقلی و مستند).

| فایل | توضیح |
|---|---|
| `tsconfig.base.json` | پایه تنظیمات TypeScript برای پکیج‌ها و اپ‌های آینده |
| `env.example` | الگوی متغیرهای محیطی — فقط نام متغیر، بدون مقدار واقعی |

## قواعد

- هیچ مقدار محرمانه (توکن، رمز، کلید) در این پکیج یا هرجای مخزن قرار نمی‌گیرد.
- `.env*` هرگز commit نمی‌شود؛ فقط `.env.example` با مقادیر placeholder.
- در فاز Backend، تنظیمات سرویس‌ها از این پکیج خوانده می‌شود تا یکپارچه بماند.
